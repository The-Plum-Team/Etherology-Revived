# Alchemy

Record Brewing Cauldron setup, valid recipes, invalid/corrupting operations,
potion handling, warp/corruption effects, inventory changes, particles, sounds,
and save/reload behavior.

For each scenario, record inputs, order of interaction, player state before and
after, output, and screenshot filenames. A staged cauldron is visual evidence
only.

The port passes this area when recipe matching and serialization agree across
loaders and all visible/audio feedback matches the reference intent.
