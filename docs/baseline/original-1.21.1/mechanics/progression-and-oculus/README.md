# Progression, Teldecore, Oculus, Ocular, and Prana Vision

Record progression gates, Teldecore research state, Oculus aspect discovery, and
the visible overlays produced by the available vision items.

For every capture, record the exact Etherology JAR, player progression state,
held/equipped item, action, expected overlay, and screenshot filename. The
published `0.1.7` reference does not contain every mechanic present in source
`0.1.8`; mark source-only mechanics explicitly instead of treating them as a
reference failure.

The port passes this area when progression persists after save/reload, server
authority is preserved, and equivalent Fabric/Forge visuals are captured.
